# 团长内容增长 Agent 首版原型设计

**日期：** 2026-08-16  
**状态：** 待用户书面审阅  
**取代范围：** 本文取代旧原型中“用户逐步选择后生成”和“生产环境模拟复盘”的交互假设；正式生产架构仍以系统总设计为准。

## 1. 产品判断

首版不是内容运营 SaaS，也不是提示词生成器。它验证平台内容能力能否通过 Agent 服务团长团队：团长或其员工进入系统后，不必理解模板、逐步配置参数或反复点击，即可得到符合当前 IP 的可用口播稿；真实视频表现回流后，Agent 能形成当前租户私有的后续创作建议。

系统包含两个严格隔离的业务域：

1. **客户租户域**：团长、下属员工、IP、视频账号、创作任务和真实数据复盘；
2. **平台运营域**：平台自有爆款内容样本、内容拆解和结构模板，不对客户开放。

生成编排服务在内部组合“平台已启用结构 + 当前 IP 上下文 + 当前租户私有复盘记忆”，但不让任一方读取另一方的内部数据。

## 2. AI Native 原则

首版交互遵守以下原则：

- **结果优先**：Agent 默认完成选题、出稿和质检，直接展示一篇可使用的口播稿；
- **选择可选**：换选题、换结构、换稿和编辑是调整能力，不是必经步骤；
- **异常打断**：只有信息不足、硬风险、权限不足或模型失败时才请求人工处理；
- **上下文持续**：记住当前团队、IP、视频账号、表达边界和历史复盘，不重复建档；
- **过程可解释**：展示适配理由、质量检查和证据边界，不展示模型思维链；
- **操作可回流**：用户可返回任一步，系统只重做受影响的下游步骤；
- **高风险确定性**：成员邀请、权限授予、模板启用和锁稿必须由人明确确认；
- **记忆有边界**：租户私有复盘不自动进入平台模板，平台模板不向客户泄露。

AI Native 不等于所有页面都使用聊天框，也不等于让 AI 自动授权。权限和安全配置使用明确、可审计的确定性界面。

## 3. 角色和核心概念

| 概念 | 定义 |
|---|---|
| 平台运营方 | 维护平台爆款样本和结构模板的内部人员 |
| 团长工作空间 | 一个团长及其团队组成的客户租户 |
| 用户 | 团长或一名下属员工，每人独立登录，不共享凭证 |
| IP | 一套真实经历、能力、受众、表达风格和边界 |
| 视频账号 | 某个 IP 在抖音、视频号、小红书等平台的具体账号 |
| 创作 Run | 一次从上下文快照到可用口播稿、质检和锁稿的可版本化任务 |

一个用户可属于多个工作空间；一个工作空间可包含多个 IP；一个 IP 可关联多个视频账号；成员权限同时受功能权限和数据范围约束。

## 4. 首版信息架构

### 4.1 客户租户域

| 路由 | 任务 | 主要用户 |
|---|---|---|
| `/app/today` | 得到今日可用口播稿并按需调整 | 团长、内容运营 |
| `/app/review` | 导入真实数据并处理 Agent 已发现的问题 | 团长、运营主管、复盘人员 |
| `/app/team` | 邀请成员并分配功能和账号范围 | 团长、获授权管理员 |

顶部持续展示当前工作空间、当前 IP、当前视频账号和当前用户。普通成员只看到已授权页面和数据。

### 4.2 平台运营域

平台内部入口使用独立安全域，生产建议为 `ops.<domain>/content-brain`；原型使用 `/platform/content-brain`。客户导航不展示入口，直接访问也必须由服务端拒绝。

内容大脑是一个任务工作台，而不是多个重型后台：

```text
爆款样本 -> AI 拆解 -> 候选结构 -> 运营校正 -> 启用版本
```

## 5. 团长端今日创作

### 5.1 默认自动路径

用户进入 `/app/today` 后，系统按当前 IP 自动执行：

1. 读取 IP、表达边界、视频账号和租户私有复盘记忆；
2. 检索适用的已启用平台结构；
3. 生成多个选题方向并自动采用排名第一的方向；
4. 围绕唯一方向生成多个口播稿；
5. 自动选择质量最高的一篇；
6. 独立运行质量检查；
7. 硬门禁通过后直接展示“今日可用口播稿”。

用户不操作也能得到可复制、可编辑、可拍摄的稿件。若首次质检未通过，系统最多自动修订一次；仍未通过时展示风险和可处理动作，不无限调用模型。

### 5.2 结果页

主区域显示完整口播稿、预计时长、质量结论和主要操作。默认折叠生成过程，不使用传统多步骤向导作为主界面。

可选操作：

- 换选题；
- 换结构；
- 换一版口播稿；
- 直接编辑；
- 重新质检；
- 确认定稿；
- 查看适配理由和版本历史。

客户可看到“为什么适合当前 IP”和质量结论，但不能看到平台原始爆款样本、完整模板、内部提示词、来源和运营备注。

### 5.3 回流规则

| 操作 | 保留 | 重做 |
|---|---|---|
| 换选题 | IP 和私有复盘上下文 | 模板匹配、出稿、质检 |
| 换结构 | IP、选题 | 出稿、质检 |
| 换稿 | IP、选题、结构、候选批次 | 选择和质检 |
| 编辑稿件 | 所有上游快照 | 新稿版本和质检 |
| 已定稿后修改 | 锁定版本 | 从锁定稿派生新草稿 |
| 切换 IP | 原 Run 全部历史 | 为新 IP 创建新 Run |

回流不覆盖历史版本。每次生成保存 IP 快照、租户记忆版本、平台结构版本、模型配置版本、Prompt schema 版本和输入版本。

## 6. 团队、成员和权限

### 6.1 加入流程

1. 团长创建工作空间并自动成为 Owner；
2. 团长填写员工手机号或邮箱；
3. 选择默认角色；
4. 选择该员工负责的 IP 和视频账号；
5. 员工通过邀请使用个人账号加入；
6. 服务端按成员关系、功能权限和账号范围过滤所有访问。

成员停用后会话立即失效，历史操作和工作成果仍属于工作空间。

原型不接短信、邮件或第三方 SSO。它使用可替换的 `IdentityProvider` 接口、SQLite 用户和服务端 HttpOnly 会话，预置团长、内容运营、复盘人员和平台运营测试账号，真实验证服务端权限隔离。邀请操作在原型中生成一次性本地邀请链接；正式首版替换为真实身份服务，不改变成员、权限和数据范围模型。

### 6.2 默认角色

| 角色 | 默认能力 |
|---|---|
| 团长 Owner | 全部业务权限、成员管理和授权 |
| 运营主管 | 指定范围内创作、定稿、数据导入和复盘 |
| 内容运营 | 指定范围内生成、编辑；定稿为可选授权 |
| 数据复盘人员 | 指定范围内导入、查看和生成复盘，不修改稿件 |

首版采用“角色模板 + 少量权限开关 + 数据范围”，不建设任意角色设计器。

功能权限收敛为：查看 IP、创作、编辑、确认定稿、导入数据、生成复盘、查看复盘、管理成员。

最终权限为：

```text
成员关系 AND 功能权限 AND IP/视频账号范围
```

AI 可以根据岗位推荐最小权限，但不能自动邀请、扩大范围或授予定稿和成员管理权限。任何权限变更由服务端执行并进入审计记录。

## 7. 视频账号和真实数据复盘

### 7.1 视频账号

一个 IP 可关联多个平台账号。每个账号保存平台、名称、平台账号标识、所属 IP、负责人、数据来源、最近导入时间和启用状态。

首版数据回流优先使用 Excel/CSV 导入和单条补录。平台 OAuth 和 API 为二期，不能成为首版可用性的前置条件。

### 7.2 导入流程

1. 员工进入自己有权访问的视频账号；
2. 上传平台导出文件或补录单条视频；
3. 系统自动识别字段并让用户确认映射；
4. 使用平台视频 ID、链接、标题和发布时间匹配已发布内容；
5. 对重复快照、缺失字段和异常值给出明确报告；
6. 成功数据按采集时间追加为不可变指标快照。

错误行不使整个批次失败。未匹配内容进入待处理列表，不擅自绑定。

### 7.3 AI Native 复盘

导入完成后，Agent 主动完成账号扫描并直接告诉员工哪些内容值得处理，不先展示复杂大盘。单条复盘结合：

- 账号自身历史基线；
- 同类型内容表现；
- 发布时间和快照时间；
- 播放、完播、互动及评论；
- 对应选题、结构、锁定稿和实际编辑差异；
- 数据完整度和证据局限。

输出“发生了什么、数据支持什么、什么只是可能原因、建议保留什么、下一条怎么做”。员工可补充线下咨询、成交反馈和评论区语境。

确认后的结论只形成当前租户、当前 IP 或当前账号的私有创作记忆，用于后续选题和结构排序；不自动修改平台模板。

### 7.4 模拟复盘隔离

模拟数据只允许开发模式显式启用：

- 生产 UI 不显示模拟发布或模拟复盘入口；
- 生产 API 禁用模拟命令；
- 模拟数据不进入真实指标表、租户记忆或平台内容大脑；
- 生产复盘只接受真实导入数据；
- 自动化测试使用独立 fixture，不伪装为生产数据。

## 8. 平台内部内容大脑

### 8.1 数据归属

爆款样本、拆解结果和结构模板是平台运营方内部资产。客户无权检索、导出或浏览。租户私有稿件和指标也不因使用平台模板而成为平台样本。

### 8.2 首版工作流

1. 平台运营人员导入或粘贴有权用于内部分析的高表现内容；
2. 保存原文、平台、作者、来源、采集时间和已有表现数据；
3. Agent 拆解受众矛盾、钩子、结构节点、证据、情绪、行动引导和风险；
4. Agent 对多条已确认样本聚类并提出候选结构；
5. 运营人员修正不可复用事实、适用 IP、边界和质量规则；
6. 人工明确启用结构版本；
7. 生成服务只读取已启用版本。

模板不是运营人员从空白表单手写的一整段 Prompt，而是 Agent 从样本提炼、运营校正的业务结构。底层系统 Prompt、模型密钥和安全约束由工程配置管理，与业务结构分离。

### 8.3 内容大脑界面

采用三栏任务工作台：

```text
样本列表 | 当前样本及 AI 拆解 | 候选/已启用结构
```

首版界面只支持导入、拆解重试、人工修正、从样本提炼、预览、启用、停用和查看版本。版本、来源链接和审计在技术层保留，不扩展为重型发布中心。

### 8.4 结构检索

生成服务先确定性过滤未启用、风险冲突和不适用结构，再按 IP、受众、选题目标、证据完整度及租户私有偏好排序，仅把少量候选传给生成 Agent。

没有专用结构时可使用已启用的通用基础结构；没有任何合格结构时必须中止并产生平台告警，不能使用草稿或伪造可靠性。

## 9. 双域隔离和受控连接

### 9.1 服务边界

- **身份与团队服务**：用户、工作空间、成员、角色和数据范围；
- **租户内容服务**：IP、视频账号、创作 Run、锁稿和租户记忆；
- **指标复盘服务**：导入、匹配、指标快照、复盘和证据；
- **平台内容大脑服务**：样本、拆解、结构及版本；
- **生成编排服务**：在内部读取两侧受控输入并生成结果；
- **审计服务**：权限、锁稿、结构启停和敏感操作。

### 9.2 安全约束

- 所有客户数据必须带 `tenant_id`，并在服务端验证成员关系、能力和账号范围；
- 平台内容大脑使用独立平台角色和接口受众，客户会话不可复用；
- 客户响应不包含模板正文、Prompt、样本来源或内部评分；
- 平台运营人员默认不能浏览租户私有指标和复盘；
- 客户数据如未来用于平台优化，必须经过明确授权、脱敏和独立流程；
- API Key 仅在服务端读取，不进入浏览器、数据库、日志和导出文件。

- `PUT /api/app/team/members/{id}/access`
- `POST /api/app/metrics/import`
- `POST /api/app/reviews/generate`

### 11.2 平台内部

- `GET/POST /api/platform/content-samples`
- `POST /api/platform/content-samples/{id}/analyze`

## 12. 错误和恢复

| 场景 | 系统行为 |
|---|---|
| 模型超时或限流 | 保存检查点，有限重试，只恢复当前 Agent 步骤 |
| 模型输出不符合 schema | 一次结构修复，失败后展示明确错误 |
| 自动路径中途失败 | 保留已生成候选和上下文，允许重试或人工选择 |
| 权限不足 | 服务端拒绝，不返回目标是否存在等越权信息 |
| 导入部分失败 | 提交有效行并生成逐行错误报告 |
| 视频无法匹配 | 进入待处理，不自动绑定 |
| 结构新版本启用失败 | 原已启用版本继续服务，不产生半发布状态 |
| 页面刷新 | 从持久层恢复当前结果、版本和待处理动作 |

## 13. 原型和生产边界

### 13.1 首版原型必须验证

- 团长首次建立 IP 后，后续默认使用当前 IP；
- 进入每日创作后无需选择即可获得一篇通过质检的可用稿；
- 用户可从结果页回流换选题、换结构、换稿和编辑；
- 多名员工独立登录，团长可按角色和账号范围授权；
- 未授权成员无法看到其他 IP 或视频账号；
- 员工可导入真实数据并获得 Agent 主动复盘；
- 复盘确认后只影响当前租户后续创作；
- 平台运营可从样本提炼并启用结构；
- 客户无法访问平台内容大脑或模板原文；
- 开发模拟复盘在生产模式完全不可见、不可调用。

### 13.2 二期

- 平台 OAuth 和数据 API；
- 爆款内容自动采集；
- SSO、企业组织层级和自定义角色；
- 多服务器负载和独立任务队列；
- 模板效果统计和自主优化候选；
- 数字人口播、音频和成片链路；
- 未经人工确认的模板自动启用明确不进入当前规划。

## 14. 默认数据和上线清理

开发默认数据用于原型跑通，必须由独立 `seed:demo` 初始化命令导入，并带 `data_origin=demo`。生产启动不自动导入演示数据；上线前可一次性删除全部 demo 数据，不影响 schema、业务代码或正式基础结构。

正式环境至少需要平台运营审核并启用一个通用基础结构。正式基础结构通过正式内容大脑流程创建，不与 demo seed 混用。

## 15. 测试重点

- 自动创作默认路径和一次自动修订；
- 每种回流只使正确的下游版本失效；
- 锁定稿不可覆盖；
- 角色模板、权限开关和 IP/账号范围交叉验证；
- 停用成员后会话失效；
- 导入去重、部分失败、快照追加和内容匹配；
- 复盘证据边界与租户私有回流；
- 平台模板接口对客户角色始终拒绝；
- 未启用模板永不进入生成；
- 结构切换失败继续使用原启用版本；
- 模拟命令在生产配置下返回不可用；
- API Key、Prompt 和平台模板正文不进入客户端 bundle 或客户响应；
- 桌面和移动端结果页、复盘页、团队授权页及内容大脑的可访问性。

## 16. 验收标准

1. 团长完成首次 IP 初始化后，下一次进入直接看到当前 IP 的可用口播稿；
2. 用户不选择选题或稿件，系统仍完成选题、出稿和质检；
3. 用户可回流调整且历史结果不丢失；
4. 团长可邀请员工并将其限制在指定 IP 和视频账号；
5. 员工只能执行被授权的创作、定稿、导入或复盘动作；
6. 真实数据导入后，Agent 自动匹配并指出需要处理的内容；
7. 确认后的复盘影响当前租户后续推荐，但不修改平台模板；
8. 平台运营可完成样本导入、AI 拆解、结构提炼、预览和启用；
9. 客户端无法发现或读取平台模板和样本；
10. 生产环境不展示也不能调用模拟发布和模拟复盘；
11. 所有关键生成、权限、锁稿和模板启停操作可追溯；
12. 原型保持结果优先，不退化为用户逐步填表和点击的传统 SaaS 流程。

## 17. 已确认 UI 视觉与交互基准

代码实现以前必须以 `docs/ui/2026-08-17-ai-native-ui-visual-spec.md` 为 UI 冻结稿，并以其中五张已选视觉图作为页面层级、密度和视觉语言的基准。

冻结范围包括：

1. 首次建档使用“我理解的你”式 AI 肖像确认，不使用长表单或多步向导；
2. 建档成功后保存当前 IP 和首个视频账号，后续登录直接进入当前 IP 的每日创作；
3. 今日创作以完整可用口播稿为主体，并保留换选题、换讲法、编辑和定稿回流；
4. 复盘以账号级结论、证据和确认后的私有记忆影响为主体；
5. 团队授权使用自然语言委托、Agent 权限解释和人工确认，不暴露技术权限矩阵；
6. 平台内容大脑以已启用内容结构和 Agent 复核判断为主体，继续保持客户域隔离；
7. 客户域不使用常驻侧边栏；顶部提供轻量任务入口和当前团队、IP、账号、用户上下文；
8. 生产环境不出现模拟发布或模拟复盘入口；数字人口播、平台 API 和运维治理仍属于二期。

用户对冻结稿最终确认之前，不进入产品代码实施。
