# 爆款样本拆解与结构启用实施计划

> **面向 Agent 开发执行者：** 必须使用 `superpowers:subagent-driven-development`（推荐）或 `superpowers:executing-plans`，按任务逐项实施。所有步骤使用复选框（`- [ ]`）跟踪。

**目标：** 将当前只读的平台内容大脑升级为可运行的“新增爆款样本 → Agent 拆解 → 人工复核 → 试生成 → 版本启用 → 团长创作使用”闭环。

**架构：** 在既有 Next.js 单体和 SQLite 应用数据库内新增平台私有的样本修订、拆解版本、结构候选、来源关系、试生成与启用审计表。Agent 只输出结构化建议；状态迁移、版本、权限和启用由确定性服务控制。团长创作仅通过结构检索器读取已启用的脱敏结构包，并在创作谱系中锁定结构版本。

**技术栈：** Next.js 16、React 19、TypeScript、SQLite / better-sqlite3、Zod、ExcelJS、OpenAI-compatible LLM、Vitest、Testing Library、Playwright。

## 全局约束

- 全部新增实施文档和业务文案使用中文，专业术语可保留英文。
- 所有平台内容资产接口必须先验证 `AccessContext.audience === "platform"`，再读取数据库。
- 团长、租户成员和租户管理员不能读取样本原文、拆解详情、来源关系、内部评分或运营备注。
- 运营人员新增的是爆款样本，不提供“新建空白模板”。
- 首版只支持粘贴文案及 `.txt`、`.srt`、`.vtt`、`.csv`、`.xlsx`；链接仅作来源记录，不自动抓取。
- 首版不处理视频/音频、不调用 ASR、不接平台 API、不自动启用结构。
- Agent 不能直接改变状态、启用、停用或回退结构版本。
- 只有已启用的不可变结构版本可以参与团长端创作。
- 试生成不得写入租户 Run、发布记录、指标、复盘或长期记忆。
- 运行中的创作任务必须锁定启动时使用的结构版本，不因后台启用新版本而漂移。
- 所有写接口使用 Zod，并使用幂等键或 `expectedVersion` 防止重复写和覆盖新版本。
- 模型结构输出只允许一次 Schema 修复；失败后保留输入与失败状态，允许人工重试。
- 使用 TDD：先看见失败，再写最小实现；每个任务形成独立提交。
- 不修改已经执行的 `004_platform_content_brain.sql`，数据库扩展使用新迁移 `008_content_brain_breakdown.sql`。
- 保留现有单机 4C8G 首版部署边界，不引入队列、Redis、对象存储或新运行时依赖。

## 计划自审结论

### 规格覆盖

- 样本新增、格式边界、去重和修订：任务 1–2；
- Agent 拆解、不可复用事实、证据引用与一次修复：任务 3；
- 归入/升级/新建、试生成、人工启用和回退：任务 4；
- 平台专用接口与租户预读取拒绝：任务 5；
- AI-native 活文档工作区、状态和可访问性：任务 6；
- 已启用结构进入团长创作并锁定谱系：任务 7；
- 演示基线、一次性清理、文档和完整验收：任务 8。

### 边界检查

- 没有加入视频下载、ASR、平台 API、队列、Redis 或自动启用；
- 没有把 IP 全局切换混入本计划；该能力应使用独立设计和实施计划推进；
- 没有让租户 API 直接读取平台样本或结构详情；
- 没有修改旧迁移文件；
- 每项实现均有明确文件、接口、测试和完成条件。

### 类型一致性

- `TemplatePackage` 在任务 1 定义，任务 4 由检索器返回，任务 7 由创作链路消费；
- 样本、拆解和候选状态名称在领域类型、仓储、服务和接口中保持一致；
- 所有人工写入统一使用 `expectedVersion`；
- 结构版本锁定统一落在 `creation_run_context.structure_version_ids_json`。
