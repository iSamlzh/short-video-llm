# 内容增长 Agent 首版 UI 视觉与交互冻结稿

> 状态：五个关键界面视觉方向已由用户逐页选定，等待代码实施前最终确认。  
> 适用范围：首版原型和首版生产实现。  
> 上位设计：`docs/superpowers/specs/2026-08-16-ai-native-team-content-agent-prototype-design.md`。

## 1. 产品体验原则

首版不是内容运营 SaaS，也不是 Prompt 配置台。界面以“Agent 已完成的结果”为主，以设置、筛选和流程状态为辅。

1. **结果优先**：先展示 Agent 已完成的 IP 理解、口播稿、复盘结论、权限解释或结构判断。
2. **自然语言委托**：用户表达业务意图，Agent 负责转译为结构化任务；界面展示 Agent 的理解供人确认。
3. **证据可见**：关键判断必须同时显示依据、适用范围、不确定项和版本。
4. **高风险人工确认**：IP 事实、定稿、权限、创作记忆和平台结构启用不得静默生效。
5. **记忆有边界**：租户私有复盘只影响当前租户/IP/账号；平台结构不向客户泄露；租户数据不进入平台内容大脑。
6. **过程可回流**：每日稿可换选题、换讲法、编辑；复盘可补业务反馈；权限可改安排；结构可复核和回滚。
7. **低操作负担**：不强迫用户逐步选择。默认路径可从当前 IP 自动生成一篇可用稿。

## 3. 信息架构与入口

### 3.1 客户域

客户域只提供三个长期任务入口：

- **今日创作**：默认入口；回到当前 IP 的最新可用稿。
- **复盘与优化**：导入真实数据并处理 Agent 主动发现的问题。
- **团队与权限**：邀请成员并设置 IP、账号和操作范围。

桌面端不使用常驻侧边栏。顶部细栏采用文字导航，不使用胶囊 Tab：

```text
内容增长 Agent / 今日创作 · 复盘与优化 · 团队
当前团队 / 当前 IP / 当前账号 / 当前用户
```

- 品牌名点击回到 `/app/today`。
- 当前任务使用墨色加粗和底部 1px 朱红线，非当前任务为弱化文字。
- 团队、IP、账号和用户均为上下文菜单；菜单使用白纸浮层和细边线，不使用大圆角和重阴影。
- `新增 IP` 只出现在 IP 上下文菜单；日常进入不重复要求选择 IP。
- 普通成员只看到有权限的入口、IP 和账号；客户端不得先拉取完整列表再隐藏。

### 3.2 平台运营域

平台内容大脑使用独立安全域、独立登录会话和独立页头。客户域不展示任何入口；无权限直接访问时返回统一拒绝页，不泄露资源是否存在。

内部入口收敛为一个任务工作台：导入样本、处理复核提案、查看已启用结构。样本原文、完整结构和运营备注仅在内部域可见。

## 4. 视觉系统

### 4.1 颜色

| Token | 值 | 用途 |
|---|---:|---|
| `--paper` | `#f4f1e8` | 页面底色 |
| `--sheet` | `#fbfaf6` | 文档、输入和浮层 |
| `--ink` | `#1b201c` | 主文字 |
| `--muted` | `#6e746e` | 说明、元数据 |
| `--line` | `#cfcabf` | 分隔线、输入边线 |
| `--accent` | `#d84c31` | 结果句、主按钮、关键动作 |
| `--success` | `#2f6548` | 已验证、通过、已启用 |
| `--warning` | `#a96618` | 待确认、不确定、证据不足 |
| `--danger` | `#9e3428` | 阻断和破坏性动作；不得与主动作并列抢色 |

禁止渐变、玻璃效果、彩色大面积背景、重阴影和以颜色代替文字含义。

### 4.2 字体

- 标题、结果句和长文案：`Noto Serif SC`, `Source Han Serif SC`, `Songti SC`, `STSong`, serif。
- 控件、元数据和短说明：`Noto Sans SC`, `Microsoft YaHei`, sans-serif。
- 全产品最多两套字体族；正文最小 16px，元数据最小 13px。
- 长文案桌面端单行不超过约 42 个汉字；脚本正文行高 1.75–1.9。

### 4.3 尺寸与间距

- 桌面基准画布：1440 × 1024；内容最大宽度 1360px。
- 顶部细栏：48px；页面横向留白 48–64px。
- 主结果区上下留白 36–48px。
- 双栏布局：主文档约 66%，证据栏约 34%，中间 1px 分隔线。
- 基础间距序列：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64px。
- 圆角仅 0 / 2 / 4 / 6px；按钮不做胶囊形。
- 阴影默认无；上下文菜单仅允许非常轻的环境阴影。

### 4.4 通用组件

1. **编辑部页头**：品牌、任务入口、当前上下文。
2. **结果引言**：朱红色一句话结论 + 一句解释；每页只允许一个主结论。
3. **动作对**：一个朱红主动作 + 一个描边次动作；其他操作降为文字动作。
4. **活文档**：正文、细分隔线、局部编辑图标和版本信息。
5. **证据边栏**：展示依据、限制、生效范围和版本；不得堆 KPI 卡片。
6. **连续清单**：行分隔替代独立卡片；展开项仍属于同一张纸面。
7. **状态标记**：图标 + 文本同时表达；避免只用颜色或胶囊 Badge。
8. **版本记录**：显示版本号、时间、确认人和变化目的，不暴露 Prompt 或密钥。

图标使用同一套线性图标库。禁止 emoji、手绘 SVG、字符图标和装饰性图标滥用。

## 5. 页面交互冻结

### 5.1 首次 IP 建档——“我理解的你”

**触发条件**：用户所属工作空间没有可用 IP；或有新增 IP 权限的用户主动选择 `新增 IP`。

**默认路径**：

1. 用户用自然语言介绍经历、擅长、服务人群、表达方式和不能越过的边界；可以粘贴文字，语音输入作为渐进增强。
2. Agent 输出一份可阅读的 IP 肖像，而不是回填表格。
3. 已确认事实、不确定事实和表达判断分开显示；涉及人数、业绩、收益或品牌背书的事实必须明确确认或补证据。
4. 用户只需回答仍阻断创作的最少问题，并选择首个视频账号。
5. 主动作 `这个理解准确，开始创作` 原子性创建 IP v1、首个账号和默认目标，然后进入 `/app/today`。

**后续行为**：保存 `current_ip_id` 和 `current_account_id`。下一次登录直接使用当前上下文；不再展示建档页。新增 IP 不覆盖既有 IP、稿件或复盘历史。

### 5.2 今日创作——“可直接拍的结果信”

**进入即执行**：读取当前 IP、账号、租户私有记忆和已启用平台结构；自动生成方向、选择最高置信方向、出稿、质检，必要时最多自动修订一次。

**默认呈现**：

- 主区是完整口播稿和局部编辑入口。
- 右栏是事实可信、符合表达、无收益承诺、创作依据和版本历史。
- 主动作 `复制并去拍`；次动作 `确认定稿`。
- `换选题`、`换个讲法`、`编辑这篇` 是回流动作，不跳到配置后台。

**状态规则**：

- 生成中显示当前正在完成的业务动作和已完成产物，不使用空白页或只显示转圈。
- 刷新后从持久层恢复 Run 和候选，不重复启动。
- QA 阻断时主动作变为 `处理后再定稿`，右栏给出可修复问题；不允许绕过事实和合规阻断。
- 已锁稿版本不可覆盖，修改必须生成新版本。

### 5.3 真实数据复盘——“账号复盘简报”

**默认呈现**：Agent 先给本周结论，再展示三条关键证据、不确定部分和下一周建议。右栏明确确认后的影响范围。

**核心动作**：

- `导入新数据`：首版支持 CSV/XLSX 和单条补录；平台 API 入口不在首版出现。
- `查看全部内容`：展开本期已匹配的真实视频记录。
- `补充业务反馈`：记录咨询、成交线索和线下反馈，但必须与平台指标区分来源。
- `确认并形成创作记忆`：只更新当前团队/IP/账号的私有记忆，不修改平台结构。

生产模式不得渲染模拟发布、模拟指标或模拟复盘入口，接口也必须拒绝模拟命令。

### 5.4 团队与权限——“一句话安排工作”

**默认路径**：团长用一句话描述岗位和范围，Agent 解释为最小权限，团长确认后才发出邀请。

**确认前必须展示**：

- 内容对象：工作空间、IP、视频账号。
- 成员可以做什么。
- 哪些动作仍需团长确认。
- 始终不可做的高风险动作。
- 是否意外扩大到其他 IP 或账号。

**权限执行**：最终权限始终为 `成员关系 AND 功能权限 AND IP/账号范围`。Agent 只能推荐，不得自行邀请、扩大范围或授予定稿和成员管理权限。变更必须产生审计记录；停用成员后会话立即失效。

### 5.5 平台内容大脑——“内容能力总账”

**默认呈现**：左侧连续清单展示已启用结构及其版本、适用范围、来源样本数和状态；展开后查看抽象节点、禁用条件、来源证据、生成预览和版本。右栏由 Agent 给出本周优先复核判断。

**内部流程**：

```text
授权样本 -> AI 拆解 -> 人工复核 -> 跨样本候选结构 -> 运营校正 -> 预览 -> 人工启用版本
```

- `导入新样本` 只接受有权用于内部分析的内容并记录来源。
- `处理复核提案` 进入 Agent 已排序的候选队列。
- 只有 ACTIVE 结构可以进入新创作 Run；历史 Run 不受新版本影响。
- 未启用结构、原文、内部 Prompt 和运营备注均不得进入客户响应。
- 租户私有稿件、指标和复盘记忆不得作为平台样本自动吸收。

## 6. 响应式与可访问性

- `>= 1200px`：按基准双栏/三栏布局。
- `768–1199px`：主文档优先，证据栏移到下方；顶部上下文允许横向滚动但不得截断当前 IP。
- `< 768px`：单栏；长表格改为分组行；主动作在底部安全区固定，次动作保持可见；脚本仍以连续长文呈现。
- 所有交互支持键盘焦点、Enter/Space 触发和 Escape 关闭浮层。
- 文本与背景至少满足 WCAG AA；焦点环不能只靠颜色差异。
- 动效只用于状态过渡，时长 120–220ms；遵循 `prefers-reduced-motion`。

## 7. 加载、空态、错误与权限态

- **加载**：用自然语言描述正在完成的业务动作，并保留已生成内容；不显示虚假的百分比。
- **空数据**：给出一个可执行主动作，例如 `导入第一批真实数据`，不堆产品功能介绍。
- **可恢复错误**：保留检查点，说明失败步骤、已保留内容和重试范围。
- **不可恢复错误**：展示错误编号和联系入口，不暴露模型请求、Prompt、密钥或内部模板。
- **无权限**：统一说明“你没有这个工作范围”，不返回对象名称、成员、IP 或账号是否存在。
- **删除/停用**：必须二次确认并明确影响范围；首版优先停用而非物理删除。

## 8. 明确不进入首版 UI

- 数字人、MiniMax 音频、HeyGen 成片和成片页面。
- 抖音/视频号 OAuth 与自动 API 回流。
- 自动发布。
- 自定义角色设计器和权限矩阵编辑器。
- 客户侧模板库、Prompt、爆款原文、内部评分和运营备注。
- 模拟发布/模拟复盘的生产入口。
- 灾备、高可用、蓝绿/金丝雀发布和运维大屏。

## 9. 实施验收

1. 五个关键页面在 1440 × 1024 下与各自视觉基准保持同一布局层级和视觉语言。
2. 不出现常驻侧边栏、卡片仪表盘、渐变、玻璃效果、胶囊式导航和长配置表单。
3. 首次建档后再次登录直接使用当前 IP；只有新增 IP 时再次建档。
4. 今日创作无需用户先选择方向或模板即可得到可用稿。
5. 所有回流动作保存历史版本，不覆盖锁定稿。
6. 复盘只接受真实数据；生产页面和 API 均无模拟入口。
7. 权限、定稿、创作记忆和平台结构启用均有人类确认与审计。
8. 客户域和平台运营域在路由、会话、接口和数据查询上均隔离。
9. 桌面、平板和手机关键任务可完成，键盘与屏幕阅读器可识别状态和动作。
10. 实现完成后必须用同视口截图与本文件中的视觉基准做并排视觉 QA，修正明显层级、间距、字体、颜色和响应式偏差。

## 10. 代码实施门

在用户明确回复批准本冻结稿之前：

- 不开始组件重构或页面实现；
- 不用旧原型 UI 作为新视觉基准；
- 可以继续补充文档、测试方案和数据契约，但不得将其描述为已实现。
